# 千星节点图与系统资料接入

本入口由本模板维护。它说明如何调用项目知识库适配器，不附带远端知识库语料，也不复制上游专有 Skill。

先读 [API 接入说明](../../../docs/knowledge-api.md)，以当前会话工具 schema 和 [本地适配器](../../../tools/miliastra-toolbox-mcp.mjs) 为参数依据。

## 查询路径

- 用户已给出节点名：用 `get_node_info` 获取节点条目，核对归属端、输入/输出参数和返回的来源。
- 需要某项系统或教程：用 `list_documents` 找到可区分的标题，再用 `get_document` 取正文。关键词匹配过多时根据候选标题缩小范围。
- 不知道资料名称的排障：整理触发条件、观察结果和预期，再用 `rag_search` 找线索；查到名称后回到条目或全文核对。
- 无结果时先判断是查询失败还是匹配为空；可用无关键词列表核实当前部署的资料范围。不要把网络错误写成“平台没有此能力”。

独立的名称可放在同一数组中查询；后一步依赖前一步返回的标题时顺序执行。每项结果分别检查，不能因一个条目成功就认为整批成功。

## 使用结果

回答引用实际返回的标题、节点与来源链接；指出文档快照日期和未取得的部分。同名条目按端和参数辨别，节点图的客户端条目不能当成 Lua 控件接口。

将文档事实、项目推断、模拟器结果和用户真机观察分开记录。复杂玩法先确认规则，再选择实现节点；本 Skill 不代替策划、模拟器用例或真机验证。
