# 千星客户端 2D 与 Lua 资料接入

本入口为模板原创接入说明；官方文档正文按需从服务查询，不随仓库重新授权或打包。

先读 [API 接入说明](../../../docs/knowledge-api.md)。客户端查询使用 `list_client_documents` 和 `get_client_document`，其具名参数以当前工具 schema 和 [本地适配器](../../../tools/miliastra-toolbox-mcp.mjs) 为准。

## 开发前取得依据

1. 将待实现行为归到控件、脚本生命周期、交互或挂载问题；用客户端文档列表找到相应标题。
2. 获取相关正文。首次接入通常需要客户端脚本使用指南和 API 文档；只取本轮所需内容，不依据普通 Lua、浏览器或 3D 节点经验猜平台接口。
3. 写代码前核对函数所属对象、签名、参数单位、枚举、返回值和生命周期时机；文档未说明的行为作为待验证项。
4. 返回候选或不完整结果时继续定位标题；所需签名尚未取得时，先完成独立工作，不把推测填成平台 API。

示例请求：

```json
{"titles":["客户端控件API文档"]}
```

## 工程与证据

维护源是 `src/**/*.lua`，入口保留平台生命周期，按项目规则构建为一个 Lua 文件。模拟器存档只记录产物路径、UI 与挂载，`source` 留空；旧内嵌源码先审阅合并再处理。遵守根目录 AGENTS 与 [Lua 工程说明](../../../docs/lua-modules.md)。

结果注明实际来源、可得版本和未知项。知识库正文可读、模拟器可运行与真机通过分别形成证据；新增或修复行为仍须按七步流程回归。
